# Goban Decals

Beautiful stylized goban themes with illustrated boards and varied stones.

| Theme | Preview | Variants |
| --- | --- | --- |
| [Sand and Pebbles](themes/sand-and-pebbles/) | <img src="themes/sand-and-pebbles/preview.webp" alt="A Go position played with pebbles on a grid drawn in sand" width="240"> | Dark and light pebbles |

Each theme page contains installation instructions for OGS, GoPanda2/Pandanet,
and Sabaki. The images used by OGS are served through GitHub Pages, while Sabaki
packages are published under [Releases](https://github.com/lykahb/goban-decals/releases).
