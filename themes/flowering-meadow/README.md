# Flowering Meadow

Soft, organic meadow boards arranged as organic green squares, with flowers
used as the stones. The realistic grass is challenging to make look good with a grid, so I gave the boards rather mossy fantastical look.

### GoPanda2/Pandanet

Install [`uv`](https://docs.astral.sh/uv/getting-started/installation/) and
clone or download this repository. From the `sunset-dandelions` directory, run:

```bash
uvx pandanet-tweaker replace \
  --board-default assets/boards/board-default.jpeg \
  --board-default-mode cover \
  --board-with-grid "9:assets/boards/board-9x9.jpeg" \
  --board-with-grid "13:assets/boards/board-13x13.jpeg" \
  --board-with-grid "19:assets/boards/board-19x19.jpeg" \
  --black-stone assets/stones/black-01.png \
  --black-stone-variant "assets/stones/black-*.png" \
  --white-stone assets/stones/white-01.png \
  --white-stone-variant "assets/stones/white-*.png" \
  --board-label-color "#2e331b" \
  --board-label-halo-color "#6f810b" \
  --black-territory-color "#ffcd1c" \
  --white-territory-color "#fce2d8" \
  --black-stone-label-color "#612d0a" \
  --white-stone-label-color "#5d523c" \
  --grid-color "#2e331b" \
  --coordinate-label-color "#2e331b" \
  --stone-scale 1.15
```

## Sunset Dandelions

### Sabaki

Download `sunset-meadow-dandelions.asar` from
[GitHub Releases](https://github.com/lykahb/goban-decals/releases), then install
the file through Sabaki's theme preferences.

The files under [`sabaki/`](sabaki/) contain the client-specific package
metadata and CSS. The released archive also contains copies of the canonical
JPEG board assets and PNG stone assets.
