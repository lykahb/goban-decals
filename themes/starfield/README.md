### GoPanda2/Pandanet

Install [`uv`](https://docs.astral.sh/uv/getting-started/installation/) and
clone or download this repository. From the `red-yellow` directory, run:

```bash
uvx pandanet-tweaker replace \
  --board-default ../../assets/boards/board-default.jpeg \
  --board-default-mode cover \
  --board-with-grid "9:../../assets/boards/board-9x9.jpeg" \
  --board-with-grid "13:../../assets/boards/board-13x13.jpeg" \
  --board-with-grid "19:../../assets/boards/board-19x19.jpeg" \
  --black-stone assets/stones/black-01.png \
  --black-stone-variant "assets/stones/black-*.png" \
  --white-stone assets/stones/white-01.png \
  --white-stone-variant "assets/stones/white-*.png" \
  --board-label-color "#d8b373" \
  --board-label-halo-color "#040a27" \
  --black-territory-color "#e35a37" \
  --white-territory-color "#f9e2af" \
  --black-stone-label-color "#3c250b" \
  --white-stone-label-color "#54514a" \
  --grid-color "#d8b373" \
  --coordinate-label-color "#d8b373" \
  --stone-scale 1.3
```
