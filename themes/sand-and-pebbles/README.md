# Sand and Pebbles

A grid drawn with a stick on the beach sand. The stones are dark and light pebbles.

![A Go position played with pebbles on a grid drawn in sand](preview.webp)

## Sabaki

Download
[sand-and-pebbles.asar](https://github.com/lykahb/goban-decals/releases/download/latest/sand-and-pebbles.asar), then install
the file through Sabaki's theme preferences.

## GoPanda2/Pandanet

Install [`uv`](https://docs.astral.sh/uv/getting-started/installation/) and
clone or download this repository. From this theme directory, run:

```bash
uvx pandanet-tweaker replace \
  --board-default assets/boards/board-default.jpg \
  --board-default-mode cover \
  --board-with-grid "9:assets/boards/board-9x9.jpg" \
  --board-with-grid "13:assets/boards/board-13x13.jpg" \
  --board-with-grid "19:assets/boards/board-19x19.jpg" \
  --black-stone assets/stones/black-01.png \
  --black-stone-variant "assets/stones/black-*.png" \
  --white-stone assets/stones/white-01.png \
  --white-stone-variant "assets/stones/white-*.png" \
  --board-label-color "#584933" \
  --board-label-halo-color "#e6b76b" \
  --black-territory-color "#58616b" \
  --white-territory-color "#82623a" \
  --black-stone-label-color "#cbd9e9" \
  --white-stone-label-color "#66553f" \
  --grid-color "#75654e" \
  --coordinate-label-color "#584933" \
  --stone-scale 1.15
```
